# Cormorant Garamond

Downloaded from the Google Fonts repository on 2026-10-24:
https://github.com/google/fonts/tree/main/ofl/cormorantgaramond

Copyright 2015 the Cormorant Project Authors (https://github.com/CatharsisFonts/Cormorant).
SIL Open Font License 1.1; see `CormorantGaramond-OFL.txt` alongside the font.

`cormorant-garamond-medium-latin.ttf` is the regular variable font instantiated at
weight 500 and subset to Latin U+0000–00FF plus General Punctuation U+2000–206F.
The source is `CormorantGaramond[wght].ttf` from that repository. Generated with
fontTools 4.61.1 (`varLib.instancer` and `subset`); no network font request is
made by the game. The opening dialogue uses this font with a Georgia fallback.
